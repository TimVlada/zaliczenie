# Zoo Online

## Opis projektu

Zoo Online to projekt strony internetowej przedstawiającej różne gatunki zwierząt.
Celem projektu jest stworzenie przejrzystej i estetycznej strony, na której użytkownicy mogą znaleźć podstawowe informacje o zwierzętach, ich środowisku życia oraz ciekawostki.

Projekt został wykonany w ramach zajęć z wykorzystaniem narzędzi do zarządzania projektem oraz kontroli wersji.

## Funkcjonalności

* Strona główna projektu
* Podstrony poświęcone zwierzętom
* Opisy zwierząt
* Zdjęcia zwierząt
* Responsywny wygląd strony

## Wykorzystane technologie

* HTML
* CSS
* Git
* GitHub
* Trello
